# Kir yuvish mashinasi bron qilish tizimi 

**Ushbu loyiha universitet yotoqxonasi (№3) uchun mo‘ljallangan kir yuvish mashinalarini onlayn bron qilish tizimi hisoblanadi. Tizim foydalanuvchilar va administratorlar uchun qulay interfeys, vaqt cheklovlari va xavfsiz autentifikatsiyani ta’minlaydi.**

## 🚀 Asosiy imkoniyatlar

- Xona raqami orqali ro‘yxatdan o‘tish
- Haftaning joriy ish kunlari (Dushanba–Juma) uchun bron qilish
- Vaqt oralig‘ini tanlash:
- 19:00 – 20:00
- 20:00 – 21:00
- 21:00 – 22:00
- Faol / band / ta’mirda bo‘lgan mashinalarni real vaqtda ko‘rish
- Moscow vaqti asosida avtomatik vaqt cheklovlari
- O‘z bronlarini ko‘rish (Home va alohida sahifada)

## 🛠️ Administrator (Admin)
- Foydalanuvchilar va bronlarni boshqarish

## 🧑‍💻 Texnologiyalar:
**Frontend:**

- React

- React Router DOM

- Axios

- i18next (ko‘p tillilik uz/en/ru)

- date-fns (sana va vaqt bilan ishlash)

**Backend (API bilan integratsiya):**

- REST API

- JWT token asosidagi autentifikatsiya

## Qanday foydalaniladi?
1. Syatdan ro'yxatdan o'ting ism familiya (majburiy) va xona raqamingiz bilan
2. Dushanbadan jumagacha uzingizga qulay vaqt oraligini tanlang (19:00-20:00, 20:00-21:00, 21:00-22:00) gacha
3. va 5 ta mashinalardan birini tanlang
4. Keyin mening bronlarim bulimidan o'z bronlaringizni kurishingiz mumkin

Shu bilan tamom! 😊
